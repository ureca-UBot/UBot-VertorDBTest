# 실행 결과 문서

**결론은 pgvector 사용이다.** 근거 측정은 **fairness-v2의 620개 측정**이다. 14개 DB·엔진·인덱스 구성, 124개 고정 검색 설정을 5회 재구축해 측정했다. 예상 서비스 규모는 청크 1천~1만 개이며, 합성 10k 결과를 6개 산포도로 비교했다.
